TreinaNorma - divisões do layout do login

Diagramas do que o NetBeans mostra no Design. O canvas nao exibe a imagem; a arte so aparece no F6.

1. Hierarquia (Navigator)

LoginFrame (JFrame 1200x574, undecorated, shape 48)
└── panelFundo        PainelFundo / BorderLayout      pinta a imagem
    └── panelFormulario   WEST / 600x574 / opaque=false
        └── painelCartao  arredondado / branco
            ├── lblTitulo
            ├── txtUsuario
            ├── txtSenha
            ├── chkLembrar
            ├── lblEsqueci
            ├── btnEntrar
            └── lblMensagem

Indentacao = quem esta dentro de quem. Ordem na lista = z-order (quem vem depois e desenhado por cima).

2. BorderLayout no panelFundo

3. Icones do menu "Set Layout"

[BorderLayout]   retangulo dividido em 5 areas (N, W, C, E, S)
[FlowLayout]     varios quadradinhos em fileira
[GridLayout]     grade uniforme 2x2 / 3x3
[GridBagLayout]  grade com celulas de tamanhos diferentes
[BoxLayout]      pilha vertical ou horizontal
[CardLayout]     cartoes empilhados
[Absolute/null]  icone com "ancoras" nos cantos
[Free Design]    GroupLayout, com molas (springs) verdes nas bordas

Esse menu aparece com botao direito no container -> Set Layout.

4. Guias de alinhamento no Design

Vermelho/azul tracejado = alinhamento. O container alvo fica contornado em verde/laranja quando aceita o drop.

5. O que o Design mostra x o que o F6 mostra

DESIGN (Matisse)                 RUNTIME (F6)
-------------------------------- --------------------------------
PainelFundo = cor de fundo       PainelFundo = imagem paintComponent
sem imagem                       imagem esticada em getWidth/getHeight
sem shape aplicado               cantos arredondados (setShape)
guias e molas visiveis           apenas o resultado final

Por isso a arte nunca aparece no canvas do NetBeans. Valide sempre rodando.
