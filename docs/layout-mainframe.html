5. Decisoes de aparencia

Item                     Escolha recomendada            Motivo
------------------------ ------------------------------ ---------------------------------
Moldura da janela        undecorated + setShape(18)     mesma identidade do login
Arrastar janela          mousePressed/Released no topo  reaproveita o codigo do login
Botoes da janela         customizados (- quadrado X)    sem barra nativa cinza
Fonte                    Segoe UI 12/13                 padrao do Windows, limpa
Tabela                   JTable + FlatLaf + zebra       legivel, sem plugin extra
Status                   "vencido / vence em N d / ok"  regra: validade nula = "revisar PGR"

Se preferir simplicidade maxima, use um JFrame normal (com barra do Windows) e mantenha apenas o painel azul por dentro. Mesmo codigo, menos passos.
